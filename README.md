# 🌍 تنبيهات المؤتمرات المجانية على واتساب

نظام مجاني 100% يفحص كل يوم مواقع الفرص العالمية، يختار المؤتمرات والفعاليات **بدون رسوم تقديم**، ويرتّب المرتبطة بالعلوم السياسية أولاً (⭐)، ثم يرسلها لك على واتساب الساعة 9 صباحاً بتوقيت القاهرة.

**التكلفة: صفر** — GitHub Actions مجاني للمستودعات العامة، و CallMeBot مجاني للاستخدام الشخصي.

---

## الإعداد (حوالي 10 دقائق، مرة واحدة فقط)

### 1) احصل على مفتاح واتساب المجاني (CallMeBot)
1. افتح من موبايلك https://www.callmebot.com/blog/free-api-whatsapp-messages/ وأضف رقم البوت المكتوب هناك لجهات الاتصال.
2. أرسل له على واتساب هذه الرسالة بالضبط:
   `I allow callmebot to send me messages`
3. سيرد عليك برسالة فيها **apikey** — احتفظ به.

### 2) ارفع المشروع على GitHub
1. أنشئ حساب على https://github.com (مجاني).
2. اضغط **New repository** ← سمّه `conf-alerts` ← اختر **Public** (حتى تكون الدقائق مجانية بلا حد) ← Create.
3. اضغط **uploading an existing file** وارفع كل الملفات في هذا المجلد، **بما فيها مجلد `.github`** (لو المتصفح ما رفعه، أنشئ الملف يدوياً: Add file ← Create new file ← اكتب الاسم `.github/workflows/daily.yml` والصق محتواه).

> ملاحظة: المستودع العام لا يكشف رقمك ولا مفتاحك، لأنهما يُحفظان كـ Secrets (الخطوة التالية).

### 3) أضف رقمك ومفتاحك كأسرار
في المستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**، وأضف اثنين:

| الاسم | القيمة |
|---|---|
| `WHATSAPP_PHONE` | رقمك بكود الدولة بدون + مثل `201001234567` |
| `CALLMEBOT_APIKEY` | المفتاح الذي وصلك من CallMeBot |

### 4) شغّله أول مرة
**Actions ← Daily free conferences → WhatsApp ← Run workflow**.
خلال دقيقة تصلك أول رسالة. بعدها يشتغل تلقائياً كل يوم.

---

## تخصيصه (ملف `config.py`)
- `FEEDS` — أضف أو احذف مواقع (أي موقع ووردبريس عادة له رابط `.../feed/`).
- `POLITICS_KEYWORDS` — كلمات تجعل الفرصة ⭐ وتظهر أولاً.
- `FEE_KEYWORDS` — كلمات تعني وجود رسوم فتُستبعد الفرصة.
- `ONLY_POLITICS = True` — لو تريد فقط الفرص السياسية.
- `MAX_ITEMS_PER_RUN` — أقصى عدد فرص يومياً.
- لتغيير وقت الإرسال: عدّل سطر `cron` في `.github/workflows/daily.yml` (التوقيت UTC، والقاهرة = UTC+3 صيفاً / +2 شتاءً).

## كيف يعمل
1. يقرأ RSS من مواقع مثل Opportunity Desk و Opportunities for Youth و Opportunities Corners وغيرها.
2. يقبل فقط ما هو فعالية (مؤتمر، قمة، منتدى، MUN، ورشة، مدرسة صيفية…).
3. يستبعد ما يذكر رسوم تقديم/تسجيل/مشاركة، إلا لو ذُكر صراحةً أنه مجاني أو Fully Funded.
4. يتذكر ما أرسله (`seen.json`) فلا يكرره.

## حدود يجب أن تعرفها
- الفلترة بالكلمات المفتاحية ليست مثالية: أحياناً تُذكر الرسوم داخل استمارة التقديم وليس في المنشور. **راجع الصفحة قبل التقديم.**
- "بدون رسوم تقديم" لا يعني أن السفر والإقامة مغطاة؛ علامة 💸 تظهر عند ذكر "fully funded" أو "free" صراحة.
- CallMeBot خدمة مجانية من طرف ثالث، قد تتأخر أحياناً. لو توقفت، البديل المجاني الأسهل هو بوت تيليجرام.
- GitHub يوقف المهام المجدولة لو لم يحدث أي تغيير في المستودع 60 يوماً؛ لكن النظام يحدّث `seen.json` تلقائياً فيبقى نشطاً.
